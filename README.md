# ASEAN Trade Copilot

The Next.js frontend lives in `client/`. `server/` is reserved for the backend.

## Local development

Use Node.js 20.9 or newer.

```sh
cd client
npm install
npm run dev
```

Open http://localhost:3000. Edit `client/app/page.tsx` for the homepage and
`client/app/globals.css` for its styles.

## Checks and production

```sh
npm run lint
npm run typecheck
npm run build
npm start
```
